서버 설정 안내

키 암호화에 사용할 서버 전용 Fernet 키가 필요합니다. Render의 Environment에 GROQ_KEY_ENCRYPTION_KEY를 등록하세요. 아래 명령은 새 암호화 키를 생성합니다.

python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"

암호화 키를 변경하면 기존에 저장된 개인 API 키를 복호화할 수 없습니다. 기존 키를 다시 등록하기 전까지는 Groq 분석을 사용할 수 없으므로, 이 값을 안전하게 보관하고 임의로 변경하지 마세요.
